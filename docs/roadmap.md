# Deadshift roadmap

## V0 — Playable core
- Movement
- Enemy pursuit
- Auto-fire
- Health, score, waves
- Restart
- Deterministic unit tests

## V1 — Feel
- Weapon cadence and damage tuning
- Enemy variants
- Pickups
- Hit feedback
- Basic sound and haptics

## V2 — Session progression
- Upgrade choices between waves
- Run summary
- Local high score
- Difficulty curve tuning

## V3 — Shipability
- App icon and splash art
- Device smoke testing
- Android build
- Crash/error instrumentation
- Store-readiness checklist

Physical-device validation, app-store credentials, publishing, and subjective acceptance remain human gates.
