# Deadshift

Deadshift is a lightweight portrait-mode zombie-wave survival game and a production test of the Personal GitHub ↔ ChatGPT development bridge.

## Current playable slice

- drag anywhere to move;
- survive escalating zombie waves;
- auto-fire at the nearest enemy;
- earn score for kills;
- restart immediately after death.

## Stack

Expo SDK 57, React Native, TypeScript, Vitest, and GitHub Actions.

## Run locally

```bash
npm install
npm start
```

Open the project with Expo Go or an emulator.

## Validate

```bash
npm run validate
```

See `docs/architecture.md` and `docs/roadmap.md` for the product and implementation plan.
